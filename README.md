# ប្រព័ន្ធគ្រប់គ្រង និងកត់ត្រាអ្នកជំងឺពិគ្រោះក្រៅ (មណ្ឌលសុខភាព)
### Health Center OPD Consultation & Monthly Statistical System

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងយ៉ាងពេញលេញ និងត្រឹមត្រូវស្របតាមទម្រង់ **សៀវភៅកត់ត្រាអ្នកជំងឺពិគ្រោះក្រៅ (៣២ ជួរឈរ)** និង **តារាងសង្ខេបស្ថិតិយោធិបាយប្រចាំខែ (ទំព័រ ២៣៥)** របស់ក្រសួងសុខាភិបាល នៃព្រះរាជាណាចក្រកម្ពុជា។

---

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

### ១. មុខងារនាំចូល File ចូលប្រព័ន្ធវិញ (PDF & Excel Import) - [ថ្មី!]
* **ទាញចូលពី File Excel (`.xlsx`, `.xls`, `.csv`):**
  * អាច Import ឯកសារ Excel ដែលបានទាញចេញពីប្រព័ន្ធ ឬឯកសារ Excel តារាងពិគ្រោះជំងឺក្រៅ។
  * ប្រព័ន្ធស្គាល់ឈ្មោះក្បាលជួរឈរទាំង ៣២ ជាភាសាខ្មែរ និងចាត់ថ្នាក់ទិន្នន័យដោយស្វ័យប្រវត្តិ។
* **ទាញចូលពី File PDF (`.pdf`):**
  * អាច Upload ឯកសារ PDF នៃរបាយការណ៍សៀវភៅកត់ត្រាអ្នកជំងឺពិគ្រោះក្រៅ (ដូចឯកសារគំរូដែលអ្នកបានផ្តល់ជូន)។
  * ប្រព័ន្ធដំណើរការអានទំព័រគូ-សេស (ទំព័រទី១ ជួរ ១-២០ និងទំព័រទី២ ជួរ ២១-៣២) ដោយបង្រួបបង្រួមទិន្នន័យអ្នកជំងឺម្នាក់ៗឡើងវិញពេញលេញ ៣២ ជួរ។
* **ជម្រើសរបៀបនាំចូល (Import Modes):**
  * ➕ **បន្ថែមលើទិន្នន័យចាស់ (Append):** រក្សាទុកអ្នកជំងឺដែលមានស្រាប់ ហើយបន្ថែមអ្នកជំងឺថ្មីចូល។
  * 🔄 **ជំនួសទិន្នន័យចាស់ទាំងអស់ (Replace All):** ជំនួសទិន្នន័យចាស់ដោយទិន្នន័យក្នុង File ថ្មី។
  * មានតារាង **មើលទិន្នន័យជាមុន (Preview Table)** មុននឹងសម្រេចចិត្តរក្សាទុក!

### ២. សៀវភៅកត់ត្រា ៣២ ជួរឈរ (Daily OPD Register - 32 Columns)
* ឆ្លុះបញ្ចាំងពេញលេញនូវរាល់ជួរឈរទាំងអស់ពីលេខ ១ ដល់ ៣២៖
  * **ជួរទី ១-៤:** ល.រ, លេខកូដប័ណ្ណ, ឈ្មោះអ្នកជំងឺ, ឈ្មោះអាណាព្យាបាល (សម្រាប់កុមារ)
  * **ជួរទី ៥-១២ (ក្រុមអាយុ ៨ កម្រិត):** ០-២៨ ថ្ងៃ, ២៩ថ្ងៃ-១១ខែ, ១-៤ ឆ្នាំ, ៥-១៤ ឆ្នាំ, ១៥-២៤ ឆ្នាំ, ២៥-៤៩ ឆ្នាំ, ៥០-៦៤ ឆ្នាំ, >=៦៤ ឆ្នាំ (គណនាដាក់ជួរដោយស្វ័យប្រវត្តិ!)
  * **ជួរទី ១៣-១៤:** ភេទ (ស្រី / ប្រុស)
  * **ជួរទី ១៥-១៧:** តំបន់ទទួលខុសត្រូវ (តំបន់ ក, តំបន់ ខ, តំបន់ គ)
  * **ជួរទី ១៨:** ស្ត្រីមានផ្ទៃពោះ (សប្តាហ៍)
  * **ជួរទី ១៩-២០:** អាសយដ្ឋាន & លេខទូរស័ព្ទ, បញ្ជូនមកពី
  * **ជួរទី ២១-២២:** ប្រភេទអ្នកជំងឺ (ករណីថ្មី / ករណីចាស់/បន្ត)
  * **ជួរទី ២៣-២៥:** រោគសញ្ញា, សញ្ញាគ្រោះថ្នាក់, រោគវិនិច្ឆ័យ (កូដ ICD-10 ដូចជា J02, I10, E11, K29.1, T14.8, B08.4...)
  * **ជួរទី ២៦:** ការព្យាបាល និងវេជ្ជបញ្ជាថ្នាំ
  * **ជួរទី ២៧-២៩:** ស្ថានភាពអាហារូបត្ថម្ភកុមារ (ធ្ងន់ធ្ងរ, ទម្ងន់/អាយុ, ទម្ងន់/កម្ពស់)
  * **ជួរទី ៣០-៣២:** បញ្ជូនទៅ (Referrals), ប្រភេទបង់ថ្លៃ (P, HEF, ប.ស.ស, E), សម្គាល់ (លេខប័ណ្ណសមធម៌ / ប.ស.ស)

### ៣. របាយការណ៍សង្ខេបស្ថិតិប្រចាំខែ (Monthly Summary Report - គំរូទំព័រ ២៣៥)
* **តារាងទី ១ (ការពិនិត្យជំងឺក្រៅ):** សរុបករណីថ្មី និងសរុបពិគ្រោះជំងឺ ចែកតាម តំបន់ ក, ខ, គ, សរុប, ប្រុស, ស្រី។
* **តារាងទី ២ (សរុបករណីថ្មីតាម អាយុ និងភេទ):** បែងចែករាល់ក្រុមអាយុទាំង ៨ តាមប្រុស/ស្រី, ចំនួនបញ្ជូនទៅ, និងចំនួនប្រើប្រាស់ប័ណ្ណមូលនិធិសមធម៌ (HEF)។
* គណនាដោយស្វ័យប្រវត្តិ ១០០% មិនបាច់បូកដោយដៃឡើយ!

## 🚀 របៀបដំណើរការប្រព័ន្ធ (How to Run)

### វិធីទី ១៖ ចុចពីរដងលើឯកសារ Bat (ងាយស្រួលបំផុត)
- គ្រាន់តែចុចពីរដង (Double-click) លើឯកសារ `start-system.bat` ក្នុងថត `c:\ប្រព័ន្ធគ្រប់គ្រងអ្នកជំងឺ` កម្មវិធីនឹងបើកដំណើរការលើ Browser ភ្លាម។

### វិធីទី ២៖ តាម Command Line
```bash
cd "c:\ប្រព័ន្ធគ្រប់គ្រងអ្នកជំងឺ"
npm run dev
```
រួចបើក Browser ទៅកាន់អាសយដ្ឋាន៖ `http://localhost:3000`
